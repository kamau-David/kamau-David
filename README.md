### 🚀 Featured Project

**[KES Tracker](https://github.com/kamau-David/kes-tracker)** — A production-ready expense-tracking app for M-Pesa and Airtel Money users.

- **Frontend:** Flutter, with push notifications via Firebase Cloud Messaging
- **Backend:** Node.js, Express, PostgreSQL (Supabase), deployed on Render
- **Integrations:** Safaricom Daraja API (M-Pesa STK Push subscriptions), Africa's Talking (SMS), Gemini AI (smart categorization), Resend (scheduled email reports)
- **Status:** Preparing for Play Store launch
